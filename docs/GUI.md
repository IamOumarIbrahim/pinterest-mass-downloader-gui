# GUI User Guide — Pinterest Mass Downloader v2.0.0

## Features & Controls

The desktop interface preserves a sleek dark visual theme while exposing complete queue controls:

1. **Mode Switcher**: Select between Keyword Search and Board/Pin URL modes.
2. **Media Controls**: Configure image, video, and GIF limits, minimum width and height resolution bounds.
3. **Backend Selector**: Choose API backend (default) or optional browser backends (Chromium/Firefox).
4. **Cookie File Selector**: Optionally select a local cookie JSON file.
5. **Queue Manager**: Add, edit, remove, retry failed jobs, clear completed items, or import/export queues.
6. **Execution Control**: Start queue execution or safely request cooperative stop/cancellation.
7. **Folder Openers**: Open selected job output directory or base output folder in OS Explorer/Finder.
