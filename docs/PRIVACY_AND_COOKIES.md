# Privacy and Cookies Policy — Pinterest Mass Downloader v2.0.0

## User Privacy & Credentials Safety

1. **No Automatic Cookie Capture**: The application never extracts browser cookies or logs in automatically.
2. **Explicit User Selection**: Cookie files are used ONLY when explicitly selected by the user via GUI or CLI (`--cookies`).
3. **No Secret Storage**: Cookie contents are loaded into the scraper at runtime and are NEVER saved to settings, queue files, job manifests, or logs.
4. **Local State Persistence**: Settings and queue state are saved locally under platform-specific user directories using `platformdirs`.
5. **No Telemetry**: No analytics or tracking data is sent to external servers.
